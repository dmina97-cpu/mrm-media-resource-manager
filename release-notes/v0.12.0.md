## Điểm mới trong MRM 0.12.0 — sắp xếp lại thư mục không mất tag
- **Đổi đường dẫn thư viện**: thư mục gốc đã di chuyển, đổi tên hoặc chuyển sang ổ khác → *Libraries & Settings → Đổi đường dẫn*. MRM kiểm tra thư mục mới có khớp không rồi trỏ sang — giữ nguyên tag, ghi chú, yêu thích, ảnh bìa, collection (cả dữ liệu dùng chung với plugin). Library báo *offline* có nút **Tìm lại vị trí mới**
- **File chuyển giữa các thư viện giữ được tag**: gom file từ thư mục này sang thư mục khác (cả hai đều là library) → khi quét, MRM nhận ra file đã chuyển và mang theo tag, yêu thích. An toàn: chỉ nhận khi file cũ thật sự không còn và ổ cũ đang cắm — bản sao hay ổ ngoài đang rút không bị lấy mất dữ liệu
- **Bấm Gỡ library giờ báo trước**: số resource / file có tag, ghi chú, yêu thích sẽ mất, kèm cách làm đúng cho từng trường hợp (đổi đường dẫn, quét lại, gom thư mục, loại trừ khi quét). Có dữ liệu sẽ mất thì phải tick xác nhận

## Plugin HNH SFX Finder 0.12.3
- Bấm gỡ thư mục mở **hộp thoại hướng dẫn** thay vì báo lỗi: khi dùng chung với MRM, chỉ cách giữ tag (Đổi đường dẫn trong MRM, Quét lại, Loại quét); khi chạy độc lập có nút **Nối lại** và **Loại quét** ngay trong hộp thoại
- Thông báo lỗi gọn, không còn bị cắt cụt

## Cài trên Mac (bản chưa ký số với Apple)
- **MRM**: mở file `.dmg`, kéo MRM vào Applications. Lần đầu bị chặn → *System Settings → Privacy & Security → Open Anyway*. Nếu báo "damaged": chạy `xattr -dr com.apple.quarantine /Applications/MRM.app` trong Terminal
- **Plugin**: thoát Resolve, giải nén, chạy `sh install_mac.sh` trong Terminal (nhập mật khẩu máy)
