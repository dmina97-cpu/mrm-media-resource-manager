### Cài trên Mac (bản chưa ký số với Apple)
- **MRM**: mở file `.dmg`, kéo MRM vào Applications. Lần đầu mở bị chặn → *System Settings → Privacy & Security → Open Anyway*. Nếu báo "damaged": chạy `xattr -dr com.apple.quarantine /Applications/MRM.app` trong Terminal
- **Plugin**: thoát Resolve, giải nén, chạy `sh install_mac.sh` trong Terminal (nhập mật khẩu máy)
- Bản Mac mới phát hành lần đầu — gặp lỗi gì gửi file chẩn đoán (Settings → Báo lỗi) cho nhà phát triển

## Điểm mới trong MRM 0.11.0
- **Duyệt theo thư mục trong Media Browser**: cột cây thư mục bên trái (library → thư mục con, kèm số file). Bấm một thư mục để xem file trong đó (gồm cả thư mục con) — vẫn lọc, tìm kiếm, AI như bình thường. Inspector có link “Xem cả thư mục này”
- **Thư mục yêu thích**: bấm ☆ trên cây thư mục (hoặc chuột phải vào file → *Ghim thư mục chứa file*). Thư mục đã ghim hiện ở đầu cây thư mục và ở thanh bên dưới *Media yêu thích* — bấm là mở đúng thư mục
- **Menu chuột phải**
  - All Resources: *Mở thư mục chứa*, *Sao chép đường dẫn*, *Yêu thích*, *Xem file media trong gói*
  - Media Browser: *Nghe thử / Xem trước*, *Mở vị trí trong Explorer*, *Sao chép đường dẫn* (nhiều file cùng lúc), *Yêu thích*, *Xem cả thư mục này*, *Đặt làm ảnh bìa*
