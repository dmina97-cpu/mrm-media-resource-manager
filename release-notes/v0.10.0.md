## Điểm mới trong MRM 0.10.0
- **Collections**: tự nhóm resource và file media theo ý bạn (vd: “SFX vlog”, “LUT điện ảnh”) — tạo ở thanh bên, thêm từ Inspector hoặc chọn nhiều mục cùng lúc
- **Xem bên trong RAR / 7Z** (trước chỉ ZIP): duyệt file, nghe/xem thử, ảnh bìa tự động từ bên trong. File nén có mật khẩu được báo rõ
- **Đổi ảnh bìa nhanh**: bấm vào ảnh bìa rồi dán ảnh (Ctrl+V), hoặc nút “Đổi ảnh bìa”; trong Media Browser có nút “Đặt làm ảnh bìa” cho ảnh/video
- **Báo lỗi dễ hơn**: Libraries & Settings → Báo lỗi → Xuất chẩn đoán (không chứa đường dẫn, tên thư viện hay ghi chú của bạn)
- Bản cài được build tự động trên GitHub Actions

## Cài đặt
- **MRM 0.9.0 trở lên**: app tự báo bản mới → bấm *Cập nhật ngay*.
- **MRM 0.8.0 hoặc cài mới**: chạy file .exe (Windows SmartScreen cảnh báo → More info → Run anyway). Cài đè giữ nguyên dữ liệu.
- **Plugin**: đóng Resolve → giải nén → chuột phải `install_windows.bat` → Run as administrator.
